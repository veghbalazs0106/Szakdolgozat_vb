# Szakdolgozat_vb
Ez a repository tartalmazza a szakdolgozattal kapcsolatos fájlokat, dokumentumokat. A CSV fájlokat, amik adatforrásként szolgáltakl és a programkódot, ami a számításokért felelt. Emellett az eredményeket is tartalmazza.

- A python kódot, ami a számításokat végzi a leiro_stat.py fájl tartalmazza.
- Az adatbázisokat, amiket használtam a kutatás során a CSV kiterjesztésű fájlok tartalmazzák.
- Az eredményeket, amiket a dolgozat táblázataiba és szövegébe helyeztem az XLSX kiterjesztésű fájlok tartalmazzák.
- Az eredményeket, amelyeket ábrák formájában helyeztem el a dolgozatban a PNG kiterjesztésű fájlok tartalmazzák.
